# תן לי לגדול · ChaniLi Studio

סרטון מרגש ומעצים להורים על פיתוח כישורים חברתיים אצל ילדים.
‏9:16, ‏1080×1920, ‏24fps, ‏2:00 דקות. מבוסס על הסטוריבורד (`reference/storyboard.png`) ועל סיכום ההרצאה של תעצומות.

הצילומים, הקריינות והמוזיקה חייבים להגיע ממחוללי וידאו ושמע או מהפקה אמיתית. לכן הסקריפט **מסרב** לבנות את הגרסה הסופית כל עוד חסר נכס, כדי שאף טיוטה לא תיראה בטעות כמו הסרטון הגמור.

## איך מסיימים את הסרטון

1. **דמויות:** לפי סעיף 0 ב-`PROMPTS.md`, יוצרים תמונות ייחוס לילד, לאמא ולתינוק.
2. **וידאו:** לכל שוט יוצרים פריים פתיחה ומנפישים אותו (Veo / Kling / Runway). שומרים כ-`footage/A01.mp4` עד `footage/A23.mp4`.
3. **קריינות:** שומרים כל שורה כ-`vo/v01.wav` עד `vo/v39.wav`.
4. **מוזיקה ואפקטים:** `music/score.wav` וקבצי `sfx/*.wav`.
5. בודקים מה חסר, מה קצר מדי ואיזו שורת קריינות עולה על הבאה:
   ```bash
   python3 tools/build.py --check
   ```
6. אפשר לבנות טיוטה בכל שלב. שוטים שכבר נוצרו נכנסים, ובמקום החסרים מופיע הפאנל מהסטוריבורד עם סימון PLACEHOLDER:
   ```bash
   python3 tools/build.py --draft
   ```
7. כשהכול קיים, בונים את הגרסה הסופית:
   ```bash
   python3 tools/build.py
   ```

דרוש רק ffmpeg (עם libass) ו-Pillow.

כל התזמונים נמצאים ב-`timeline.json`:
- `shots`: זמני כל שוט, נקודת הכניסה בקליפ (`in`), סוג המעבר וגרייד.
- `vo`: מתי כל שורה נכנסת (`at`). הכתוביות מסתנכרנות אוטומטית לאורך האמיתי של כל קובץ קריינות.
- `subtitles`: אילו משפטים מוצגים על המסך.
- `music.envelope`: עוצמת המוזיקה לאורך הסרטון (dB). מעליה פועלת הנמכה אוטומטית בכל פעם שהקריינית מדברת.
- `sfx`: אפקטים ואווירה, עם זמן, אורך ועוצמה.

## כתוביות

רק המשפטים המרכזיים מופיעים על המסך, בגופן Heebo, מעל אזור הממשק של רילס וטיקטוק:
- שורת הילד בגוון חם ובמרכאות.
- הציטוטים של האמא (״אני מבינה שנפגעת.״) בגופן דק.
- ״אני יכול לנסות / ללמוד / להתמודד״ נבנה שורה אחר שורה, כל שורה עם המילים שלה.
- ״הם יצעדו בעולם בעצמם.״ גדול ובזהב.

הגופנים (Heebo, ‏Amatic SC, ‏Cormorant Garamond, כולם ברישיון SIL OFL) נמצאים ב-`fonts/`.
