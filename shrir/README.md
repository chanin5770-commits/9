# שריר שצריך לאמן

סרטון אנכי על פיתוח מיומנויות חברתיות אצל ילדים, לפי סיכום ההרצאה של תעצומות והסטוריבורד בן 15 התמונות.
הסרטון מספר את הסיפור של יואב: הוא עומד בצד החצר, מקבל ליווי וכלים, מתרגל, ובסוף מצטרף למשחק.

## התוצרים

| קובץ | מה זה |
|---|---|
| `dist/shrir-film.mp4` | **הסרטון**: ‏3:13 דקות, ‏1080×1920, ‏30fps, ‏H.264 + AAC, כתוביות צרובות, מוזיקה ואפקטים (**עדיין בלי קריינות**, ראו למטה) |
| `dist/shrir.srt` | קובץ הכתוביות, מסונכרן לתזמון הסרטון |
| `dist/timings.csv` | תזמון של כל סצנה ושוט (נפתח באקסל) |
| `build/timeline.json` | ציר הזמן המלא שממנו נבנים התמונה והסאונד |
| `assets/scenes/raw/` | 15 התמונות כפי שנחתכו מהלוח, בלי שוליים, פסים ומספרים |
| `assets/scenes/clean/` | אותן תמונות, בלי הלב שהיה מוטמע בפינה (הסרטון מצייר לב משלו) |
| `assets/scenes/hd/` | אותן תמונות אחרי הגדלה פי 4 (Real-ESRGAN) |
| `content/script.json` | **מקור אחד לכל המילים**: קריינות, כתוביות, כותרות, שוטים ותנועות מצלמה |

## הקריינות: מה חסר ואיך משלימים

בסביבה הזאת לא היה שירות קריינות בעברית שמותר להשתמש בו, ולכן **אין בסרטון קול קריין**. לא נוצר קובץ קול מזויף.
בינתיים הקצב של הסרטון נקבע לפי הערכה של קריאה רגועה (כ־12.5 אותיות בשנייה), והכתוביות מעבירות את הטקסט המלא.

כדי להכניס קריינות:

1. מקליטים את כל 50 השורות של `content/script.json` לפי הסדר, בטייק אחד, עם נשימה קצרה (חצי שנייה או יותר) בין שורה לשורה. את הטקסט לקריאה אפשר לקחת מ-`dist/shrir.srt`.
2. שומרים את ההקלטה ב-`narration/narration.wav`, ואז מריצים:

```bash
python3 tools/align_narration.py narration/narration.wav   # מוצא איפה כל שורה מתחילה ונגמרת
python3 tools/build_timeline.py                            # מתזמן את כל הסרטון לפי הקול
python3 tools/score.py                                     # מוזיקה ואפקטים שמתאימים את עצמם לקול, עם הנמכה מתחת לדיבור
node tools/render.cjs                                      # רינדור מחדש (כ־16 דקות)
```

הסרטון כולו מתוזמן מחדש לפי הקול האמיתי: השוטים, הכותרות, שלבי ההצטרפות, הלב והמוזיקה. הקול לא מואץ ולא נדחס.

## החלטות עיצוב

- **מסך אנכי בלי מתיחה:** התמונות כמעט ריבועיות. בשוטים רחבים התמונה מוצגת ברוחב המסך, ומעליה ומתחתיה ממשיך עותק רך ומטושטש שלה, עם מעבר הדרגתי. בתקריבים התמונה ממלאת את כל המסך, ואף פעם לא נמתחת.
- **תנועה:** תנועות מצלמה איטיות ומכוונות (התקרבות, הסטה מיואב אל החבר, סיבוב קל מעל החישוקים) וחיתוך לפרטים מתוך אותה תמונה. אין אנימציה מזויפת של הדמויות ואין עיוות של פנים.
- **צבע:** הפתיחה קרירה ומעט רחוקה, האמצע מתחמם, והשיא והסיום באור זהוב. החזרה לחצר בתחילת השיא היא אותה תמונה מהפתיחה, הפעם באור חם.
- **הלב:** לב קטן בפינה הימנית העליונה שמתמלא בהדרגה ברגעי למידה. הוא אף פעם לא מתרוקן, ובסוף הוא מלא בכ־95% בלבד, כי הלמידה לא נגמרת.
- **טקסט:** כתוביות בגופן Assistant בתחתית, על רקע עדין. כותרות בגופן Frank Ruhl Libre בחלק העליון. הכלים למבוגרים מופיעים בשליש התחתון כדי לא לכסות פנים. כל הטקסט נשאר בתוך האזורים הבטוחים של ממשק הטלפון.
- **מיתוג:** לא צורף לוגו, ולכן בכרטיס הסיום ״תעצומות״ כתוב בטקסט בלבד.

## סאונד

המוזיקה ועיצוב הסאונד מסונתזים כולם בקוד (`tools/score.py`), בלי דגימות ובלי מוזיקה של אחרים, כך שאין בעיית זכויות.
- **מוזיקה:** סול מז׳ור, 70 BPM. פסנתר דליל בצבע מי מינור בפתיחה, פעימה רכה מהסצנה השלישית, עצירה קצרה במשחק החישוקים, כלי קשת שמתרחבים לקראת השיא, ופתרון חם על כרטיס הסיום.
- **אפקטים:** אוויר חצר וציפורים מרחוק, כדור, צעדים בהתקרבות ובריצה, מים, קוביות עץ, וצליל פעמון עדין כשהלב מתמלא.
- **עוצמה:** נורמליזציה ל־‎-16 LUFS (מתאים לטלפונים), בלי קפיצות. כשתהיה קריינות, המוזיקה תרד בכ־8dB מתחת לקול.

## מגבלות

- **רזולוציית המקור:** כל תא בלוח הוא כ־300×300 פיקסלים בלבד. ההגדלה ב-Real-ESRGAN משפרת קווים וחדות, אבל לא יוצרת פרטים שלא היו במקור. בתקריבים (02, 07, 11) רואים מרקם רך ו״מצויר״ מעט.
- **אין הנפשת דמויות:** בסביבה לא היה כלי ליצירת וידאו מתמונה, ולכן התנועה היא של המצלמה בלבד.
- **ההרחבה האנכית מטושטשת בכוונה:** לא היה כלי להשלמת רקע יצירתית.

## בנייה מאפס

```bash
npm install                                  # playwright (משתמש ב-Chromium המותקן)
pip install opencv-python-headless scipy torch spandrel
python3 tools/prepare_assets.py              # חיתוך הלוח והסרת הלב המוטמע
ESRGAN_WEIGHTS=path/RealESRGAN_x4plus.pth python3 tools/upscale.py
python3 tools/build_timeline.py
python3 tools/score.py
node tools/render.cjs                        # dist/shrir-film.mp4
node tools/render.cjs --clean                # בלי כתוביות צרובות (לפלטפורמות עם כתוביות משלהן)
node tools/render.cjs --stills 10,62,135     # פריימים בודדים לבדיקה
```
