## רינדור מחדש

```bash
cd launch
python3 render.py                       # dist/kingdom-launch-9x16.mp4
python3 render.py --stills 10,48.5,53   # פריימים בודדים לבדיקה, ב-work/stills
```

צריך ffmpeg, ‏numpy ו-Pillow עם raqm (לעברית מימין לשמאל).
העריכה (שוטים, תזמונים וטקסטים) נמצאת ב-`film.py`, כלי הציור ב-`kit.py`, והפסקול ב-`score.py`.
