## השמע

- **השמע המקורי של כל סרטון מתנגן במלואו ובסנכרון מלא,** בלי שינוי קצב ובלי מוזיקת רקע נוספת.
- **ניקוי רעשים** (afftdn) ו־high-pass עדין לכל הסרטונים.
- **איזון עוצמות בין הסרטונים:** הסרטון הראשון, שהוקלט חלש מאוד, הוגבר ודוחס בעדינות.

- **אפקטים קוליים** (Shimmer ו־Whoosh עדינים) רק בפתיחה, בין החלקים ובסיום.
- **בפתיחה ובסיום** המוזיקה המקורית מתרככת מתחת לכותרת.

## שינוי ורינדור מחדש

הסרטונים המקוריים לא נשמרים בריפו. כדי לרנדר מחדש, שמים את 18 קובצי ה־MP4 מהדרייב בתיקייה `hanukkah/raw/` בשמות המקוריים.

```bash
cd hanukkah
pip install opencv-python-headless librosa numpy scipy pillow
python3 tools/analyze_audio.py        # ניתוח שמע (פעם אחת)
python3 tools/film.py plan            # ציר הזמן
python3 tools/film.py stills 10,60    # פריימים לבדיקה (work/stills)
python3 tools/film.py film            # רינדור הסרט המלא (4 תהליכים במקביל)
python3 tools/film.py parts           # חלוקה לחלקים לסטטוס
python3 tools/film.py highlights      # הגרסה הקצרה
python3 tools/cover.py                # תמונת השער
```

- **העריכה** (סדר החלקים, שמות החלקים, נקודות התחלה וסוף של כל סרטון): הרשימה `SECTIONS` בקובץ `tools/film.py`.
- **המנוע** (קריאת וידאו, ייצוב, גריידינג, מעברים, עיצוב המסגרת, טקסט ומיקס שמע): `tools/engine.py`.
- `tools/edit.py` הוא הגרסה הקודמת (טריילר קולנועי עם רגע "סובבו את המסך").

הגופנים (Frank Ruhl Libre, ‏Heebo, ‏Suez One, ‏Bellefair) ברישיון SIL OFL, וכלולים ב־`assets/fonts`.
