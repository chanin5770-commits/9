**פונטים:** כמו באתר. הכותרות כתובות ב-Rubik 800 בסגנון הכותרת הראשית של האתר: שורה ראשונה בוורוד #ff8fc6, עם קו מתאר לבן וצללים מדורגים בוורוד כהה, ושורה שנייה בתכלת #a9dcff עם צללים כחולים. התוויות כתובות ב-Noto Sans Hebrew על רקע שמנת, עם מסגרת זהב. קובצי הפונטים נלקחו מהאתר עצמו.

כל הסרטונים מסתיימים באותה סצנה: קיר של חומרים מהערכה, שער האתר, "הצטרפי עכשיו לעולם החנוכה!", כתובת האתר והלוגו.

## עריכת הסאונד
- נעשה שימוש רק בשירים המקוריים של חני לי.
- בסרטונים 1, 2 ו-4 השיר מקוצר. החיתוך נעשה בנקודות שקטות בין משפטים, עם מעבר רך לסיום המקורי של השיר.
- בסרטונים 3 ו-5 השיר מתחיל מההתחלה ודועך בנקודת שקט.
- הקצב של כל שיר זוהה אוטומטית, וכל מעבר סצנה "נצמד" לפעמה הקרובה (`assets/audio/beats.json`).
- העוצמה מנורמלת ל-‎-14 LUFS, הרמה המקובלת ברשתות.

## איך משנים
- התסריטים (טקסטים, תזמונים וחומרים) נמצאים ב-`src/videos.js`. לכל סרטון יש מערך `cuts` עם זמני הסצנות.
- המנוע הגרפי (דפדוף תלת-ממדי, מניפה, טאבלט, קיר, ניצוצות וכיתובים) נמצא ב-`src/engine.js`.
- רינדור:

```bash
NODE_PATH=$(npm root -g) node tools/render.cjs v1                       # dist/chanukah-world-full-kit.mp4
NODE_PATH=$(npm root -g) node tools/render.cjs v3 --stills 2,10,40      # תמונות בדיקה בלבד
# v6 = מדריך, v7/v7p = הורים רגשי (בלי/עם מחיר), v8/v8p = הורים קצבי (בלי/עם מחיר). התסריטים ב-src/videos2.js
```

דרוש: Node, ‏Playwright עם Chromium, ו-ffmpeg.
