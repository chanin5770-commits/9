# קליפ – ראש חודש כסלו תשל"ח

קליפ לשיר על ראש חודש כסלו תשל"ח, לפי הסטוריבורד ובסדר מילות השיר.
ב־**0:56**, ברגע "יצא הרבי מחדרו פעם ראשונה", מופיעה **התמונה האמיתית של הרבי בשחור־לבן**, והיא חוזרת שוב ב־2:29.5 בסבב השני של השיר.

| קובץ | מה זה |

## איך הקליפ בנוי
* רק פאנלים מהסטוריבורד, עם פאות קצרות ובלי בנות. הסרטון המונפש ששלחת **לא** נכנס לקליפ, כי יש בו פאות ארוכות ורבי שנוצר ב־AI.
* תנועות מצלמה (Ken Burns), מעברים, אור זהוב, עלי שלכת, נצנוצים ופולס על הקצב (‏130 BPM).
* דאגה = צבעים קרירים. הנס והשמחה = זהב וחום.
* התמונה של הרבי נשארת כמו שהיא: בלי צבע, בלי אפקטים ובלי הנפשה. יש רק זום איטי.
