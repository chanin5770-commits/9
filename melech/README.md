## איך הקליפ בנוי

הקליפ משלב שני סוגי חומר:

**כל האותיות העבריות שנוספו בקליפ נכתבות בגופן אמיתי** (Frank Ruhl Libre, וגם Secular One לכותרת). הן אובייקטים תלת־ממדיים שבנויים מנתיבי הגופן: חזית מתכתית, עומק, הארה וסיבוב עדין. אף אחת מהן לא מצוירת על ידי מחולל תמונות.

## מגבלות

- **סנכרון שפתיים:** אין. בקטעי הדמות שצירפת הילד לא שר, ובכלים שזמינים כאן אי אפשר להנפיש פה על גבי וידאו קיים. כדי לקבל סנכרון שפתיים צריך לייצר את קטעי הדמות בכלי וידאו עם lip-sync (למשל Kling או Hedra) מתוך השיר עצמו.
- **חומר מצולם:** יש רק כ־64 שניות של קטעי דמות לשיר של כמעט 3 דקות, ולכן כל קטע מופיע כמה פעמים, בכל פעם במסגור ובתזמון אחר. כמה רגעים שהפרומפט ביקש אינם בחומר: חברים לומדים יחד, ריקוד חסידי ויד על הלב. הם הוחלפו בקטעים הקרובים ביותר שיש, או בסצנות קוד (צדקה, ״תורה״ ו״שמחה״ נבנות מאותיות). קטעי דמות נוספים ישתלבו בקלות ב־`src/timeline.js`.
- **אותיות בתוך הקליפים:** בתוך הקליפים שצירפת יש אותיות שמחולל הווידאו צייר. אותן אי אפשר לתקן, ובקטעי האל״ף־בי״ת הן מוסתרות מתחת לאותיות האמיתיות.
- **איכות:** הקליפים המקוריים הם ברזולוציה 640×360, והוגדלו ל־1080p.

## רינדור מחדש

```bash
tools/extract-frames.sh          # פעם אחת: פורס את הקליפים לפריימים ב-build/frames
node tools/render.cjs            # dist/melech-haotiyot.mp4 (צריך playwright ו-ffmpeg)
node tools/render.cjs --from 38 --to 52 --out build/part.mp4    # רק קטע
node tools/render.cjs --stills 40.2,96,170 --stills-dir build/stills
```

| קובץ | מה יש בו |
|---|---|
| `src/timeline.js` | כל השוטים וזמני השורות |
| `src/scenes.js` | הסצנות |
| `src/engine.js` | אותיות תלת־ממד, ניצוצות, אור ורקעים |
| `src/beats.js` | הפעמות וזמני האותיות, נוצר מתוך `analysis/beats.json` |
| `tools/analysis/` | סקריפטי הניתוח: הפרדת קול, תמלול בחלונות, פעמות |
