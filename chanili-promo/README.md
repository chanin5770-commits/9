## סרטון לאדריכל או לפרויקט אחר

1. שמים את התמונות החדשות ב־`assets/`.
2. מעדכנים את `config.js`:
   - `before`: צילום המודל (Revit, SketchUp וכו׳)
   - `reveal`: ההדמיה מאותה זווית
   - `shots`: ארבע הדמיות וכיתוב לכל אחת
   - `collage`: שש תמונות לקולאז׳
   - כל הטקסטים
3. מרנדרים:

```bash
node chanili-promo/tools/render.cjs                    # שתי הגרסאות
node chanili-promo/tools/render.cjs --only vertical    # רק לאורך
node chanili-promo/tools/render.cjs --stills 2,5,19    # תמונות בודדות לבדיקה
```

צריך `playwright` ו־`ffmpeg`. לצפייה עם סאונד בדפדפן מפעילים שרת מקומי בתיקייה (למשל `npx http-server chanili-promo`) ופותחים את `index.html`.

אם אין סיור תלת־ממדי לפרויקט, אפשר להפעיל את `tools/capture-tour.cjs` על סיור קיים. אפשר גם להשאיר את פריימי הסיור של עובדיה 11 כהדגמה של השירות.

## לפני פרסום

ההדמיות מציגות פרויקט של אדריכל. כדאי לקבל את אישורו לפרסום, ואפשר להוסיף לו קרדיט באחד הכיתובים ב־`config.js`.
