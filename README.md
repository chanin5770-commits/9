## כתוביות

הכתוביות צרובות בתמונה ומסונכרנות לקריינות:
- **משפטים רגילים** מופיעים בתחתית המסך, על רקע כהה ועדין, והמילה ״חשמלי״ מודגשת בזהב.
- **״עוצמה״, ״דיוק״ ו״מקצועיות״** (פאנל 8) נכנסות בגדול: המילה נוחתת על המכה, עם זוהר כחול וקו זהב.
- **״חשמלי״ האחרון** מושמע מעל הלוגו עצמו, ולכן אין לו כתובית.

## עיצוב הסאונד

מעל המוזיקה יש שכבה דרמטית:
- **על כל חיתוך:** סוול הפוך שנקטע בדיוק בחיתוך, ואז אימפקט שכבתי (בום, סאב-דרופ שיורד, צלצול מתכתי וניצוצות).
- **שנייה 18.5 ושנייה 26:** חצי שנייה של שקט מוחלט לפני המכות הכי גדולות, ואז הפיצוץ.
- **ארקים חשמליים** בכל ניצוץ, על כל מפסק, ובקווי המתח על כל מילה.
- **רעם רחוק** ב״יש חשמל...״ וב-FLASH של הלוגו.
- **WHOOSH שעובר מצד לצד** כשהמצלמה טסה בתעלות וכשהזרמים מתכנסים.
- **יבבת טעינה** לפני הדליקה של עמדת הטעינה ולפני הלוגו.

## רינדור מחדש

אחרי שינוי בקוד (`src/scenes.js` לתמונה, `src/audio.js` למוזיקה ולסאונד, `src/timeline.js` לתזמונים ולמיקום הקריינות).
כדי להחליף קריינות, שמים הקלטה חדשה ב-`assets/narration.wav` ומעדכנים את `AD.VO` ב-`src/timeline.js`: נקודת התחלה וסוף של כל משפט בהקלטה, ומתי הוא נכנס בסרטון.

```bash
npm i -D playwright      # פעם אחת
node tools/render.cjs           # dist/heshmali-ad-30s.mp4 עם כתוביות (דורש ffmpeg)
node tools/render.cjs --clean   # dist/heshmali-ad-30s-clean.mp4 בלי כתוביות
node tools/render.cjs --stills 3,15,28 --stills-dir dist/stills   # פריימים בודדים לבדיקה
```

הרינדור דטרמיניסטי: אותו זמן תמיד נותן אותו פריים, כך שהתמונה והסאונד תמיד מסונכרנים.

גופן הסלוגן הוא Heebo (רישיון SIL OFL), והוא כלול בריפו.
