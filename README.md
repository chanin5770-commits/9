# חשמלי — פרסומת קולנועית 30 שניות

פרסומת מונפשת למותג החשמל ״חשמלי״, לפי הסטוריבורד והתסריט ב-[PROMPTS.md](PROMPTS.md).
בלי דמויות ובלי טקסט מלבד הלוגו והסלוגן. כל הסאונד מסונתז בקוד.

## מה יש כאן

| קובץ | מה זה |
|---|---|
| `dist/heshmali-ad-30s.mp4` | **הסרטון המוכן**: ‏1920×1080, ‏30fps, H.264 + AAC, כולל מוזיקה ואפקטים |
| `dist/heshmali-ad-30s.wav` | פסקול בלבד (מוזיקה ואפקטים), לעריכה |

| `index.html` | נגן בדפדפן: אנימציה חיה עם סאונד, ציר זמן וכתוביות קריינות |
| `PROMPTS.md` | פרומפט מאסטר, פרומפטים ל-Kling, נוסח הקריינות והנחיות הסאונד |
| `assets/logo.png` | הלוגו בלי רקע (PNG שקוף), לעריכה ול-Kling |

## קריינות

אין בסרטון קול קריין, כי לא היה כאן מנוע הקראה בעברית. המוזיקה משאירה מקום בדיוק בנקודות הקריינות.
כדי להוסיף קריין: מקליטים (או משתמשים בהקראה של CapCut) ומניחים כל משפט לפי `dist/narration.srt`.
בנגן בדפדפן אפשר להפעיל ״כתוביות קריינות״ כדי לראות איפה כל משפט נכנס.

## צפייה בנגן

הנגן צריך שרת מקומי, למשל:

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

## רינדור מחדש

אחרי שינוי בקוד (`src/scenes.js` לתמונה, `src/audio.js` לסאונד, `src/timeline.js` לתזמונים):

```bash
npm i -D playwright      # פעם אחת
node tools/render.cjs    # dist/heshmali-ad-30s.mp4 (דורש ffmpeg)
node tools/render.cjs --stills 3,15,28 --stills-dir dist/stills   # פריימים בודדים לבדיקה
```

הרינדור דטרמיניסטי: אותו זמן תמיד נותן אותו פריים, כך שהתמונה והסאונד תמיד מסונכרנים.

גופן הסלוגן הוא Heebo (רישיון SIL OFL), והוא כלול בריפו.
