## עריכה ורינדור מחדש

ציר הזמן נמצא בסוף `src/clip.js`, ברשימה `RAW`. כל שורה: זמן התחלה, סצנה (תמונה וכיתוב), סוג מעבר ומשך המעבר.
אפשר להחליף תמונה, לשנות כיתוב או להזיז זמן, והזמנים ״נצמדים״ לפעמה הקרובה בשיר.

```bash
cd libi
python3 tools/enhance.py                     # רק אם הוספתם או החלפתם תמונות
node tools/render.cjs                        # הסרטון המלא (כ-15 דקות)
node tools/render.cjs --stills 10,45,120     # תמונות בדיקה מזמנים מסוימים
node tools/render.cjs --cover                # תמונת השער
node tools/render.cjs --timeline             # ציר הזמן כ-JSON
```

לתצוגה מקדימה חיה: מגישים את התיקייה בשרת מקומי (למשל `npx serve libi`) ופותחים את `index.html`.

## שיפור התמונות

רק תיקונים כלליים ועדינים: איזון לבן חלקי, פריסת טווח הבהירות, הבהרה של תמונות חשוכות (עד ~20%), רוויה קלה וחידוד עדין.
הפנים לא רוטשו ולא שונו. התמונות האנכיות הוגדלו ל-1080×1920 בלי מתיחה, והאופקיות מוצגות במסגרת מעל רקע מטושטש של אותה תמונה.
