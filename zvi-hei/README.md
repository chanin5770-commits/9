# צבי – מלך האות ה׳ 👑

קליפ אנכי (‎1080×1920, ‏30fps) לכבוד צבי, מלך האות ה׳ בגן.

הגרסה הנוכחית ערוכה על השיר שצירפת (`audio/song-zvi.mp3`, ‏2:46, ‏152 BPM). השיר לא נשמר במאגר.
ציר הזמן לשיר הזה (`LONG_PLAN` ב-`src/video.js`): פתיחה 0:00–0:25 (ה׳ ב-0:17.5, צבי ב-0:20.6), הֶגֶה 0:44, הֶלִיקוֹפְּטֶר 0:52, רגע רגוע 1:32, שיא 1:36, הפסקה 1:57, סיום 2:11–2:46.
הטבלה שלמטה מתארת את הגרסה הקודמת על הפסקול המקורי (`audio/song.wav`).

> התמונות של הילדים והסרטון **לא נשמרים במאגר** (הוא ציבורי). הם נמצאים רק בתיקיות המקומיות
> `photos/` ו-`out/`, שמוחרגות ב-`.gitignore`.

## הפקה מחדש
```bash
python3 tools/enhance.py      # photos/original -> photos/enhanced (+ photos/bg, out/qa)
python3 tools/compose.py      # הפסקול המקורי -> audio/song.wav
node tools/render.cjs         # -> out/zvi-melech-hei.mp4 + out/zvi-cover.jpg
node tools/render.cjs --stills 21,25.5   # פריימים לבדיקה ב-out/qa
```
**החלפת השיר:** `python3 tools/analyze_song.py audio/השיר.mp3` ואז `node tools/render.cjs`.
הכלי מזהה את הקצב ואת האורך, וציר הזמן מתאים את עצמו לתיבות של השיר.

קבצים: `src/video.js` (כל הסצנות, האנימציות והמעברים), `src/config.js` (רשת הקצב), `tools/` (שיפור תמונות, פסקול, רינדור).
נבנה עם Canvas ב-Chromium (Playwright) ו-FFmpeg. גופן: Fredoka (רישיון OFL).
