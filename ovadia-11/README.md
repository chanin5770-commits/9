# עובדיה 11: תאום דיגיטלי תלת־ממדי

סיור תלת־ממדי אינטראקטיבי בבניין, בקובץ HTML אחד (`index.html`). הקובץ משתמש ב־Three.js ‏0.160, ב־WebGL וב־Tailwind.

פתיחה מקומית: `npx http-server .` ואז לגלוש ל־`/ovadia-11/`. אפשר גם לפתוח את הקובץ ישירות. צריך חיבור לאינטרנט כדי לטעון את Three.js מה־CDN.

## מה יש בו
- מודל גאומטרי אמיתי: קירות עם פתחים וחלונות שקועים, מרפסות, מעקים, גג, חדר יציאה לגג ודודי שמש. זה לא תמונה על קובייה.
- אבן ירושלמית פרוצדורלית: נדבכים, סיתות טובזה, מפת בליטות ומפת חספוס.
- שמיים פיזיקליים עם תאורת סביבה שנגזרת מהם, צללים רכים, זכוכית מחזירה וחלונות מוארים.
- מצבי יום, שקיעה ולילה. בלילה נדלקים פנסי רחוב ותאורה על החזית.
- סיבוב 360°, ארבע חזיתות, מבט על, הליכה בגובה עיניים (WASD או ג׳ויסטיק בטלפון), נקודות עניין, מסך מלא וצילום מסך.
- סביבה: כבישים, מדרכות, חומת אבן ושער, עצים, לבנדר, מכוניות חונות ונוסעות, ואנשים הולכים.
- הכפתור ״סמן השלמות משוערות״ צובע בכתום כל חלק שלא מופיע בתמונות.
- טעינת קובץ GLB: ייצוא מה־Revit מחליף את המודל המשוער בגאומטריה המקורית.

## דיוק
המקור הקובע הוא צילום המסך מ־Revit. ההדמיות הצבעוניות שימשו לחומרים ולסביבה. המידות (רוחב ≈ 20 מ׳, עומק ≈ 16 מ׳, קומה 3.10 מ׳) הוערכו מפרופורציות התמונה.
החזית האחורית, החלק האחורי של הצד הימני ופריסת הגג הם השלמה משוערת.
לשחזור מדויק צריך תוכניות קומה, חזיתות וחתך מתיק ההיתר, או את קובץ ה־Revit עצמו.
