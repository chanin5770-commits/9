# שמוליק — מלך האות ד׳ 👑

קליפ אנכי (1080×1920, ‏30fps) לכבוד שמוליק, מלך האות ד׳ בגן, מסונכרן לשיר ״מלך האותיות״.

הכול מצויר בקוד על canvas (`src/clip.js`), כל פריים לפי הזמן בשיר. Chromium מצייר ו-ffmpeg מקודד.
זמני הסצנות נצמדים לפעמות השיר (‏152 BPM), שזוהו אוטומטית ונשמרו ב-`audio/beats.json`.

## הרצה

התמונות והשיר לא נשמרים ב-git (פרטיות). כדי לרנדר מחדש:

```bash
# תמונות מקור: photos-src/01.jpg … 19.jpg, השיר: audio/song.mp3
python3 tools/prep_photos.py photos-src photos   # שיפור עדין: הבהרה, חדות, צבע, ורקעים מטושטשים
node tools/render.cjs                              # -> out/shmulik-king-dalet.mp4
node tools/render.cjs --stills 12,16,45            # פריימים בודדים לבדיקה
```
