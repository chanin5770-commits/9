# צעד אחר צעד — אפליקציית דמו

מאמן אישי לניהול זמן, משימות והתמדה. עברית מלאה, RTL, מותאם לטלפון.

| קובץ | מה זה |
|---|---|
| `app.html` | גוף העמוד (מקור). זה מה שמפורסם כ־Artifact |
| `build.mjs` | עוטף את `app.html` לאתר עצמאי: `node build.mjs` → `index.html` |
| `index.html` | אתר עצמאי עם manifest ו־service worker (PWA מלא באחסון סטטי כמו GitHub Pages) |
| `manifest.webmanifest`, `sw.js`, `icon*.{svg,png}` | קבצי ההתקנה למסך הבית ועבודה ללא רשת |

מה אמיתי ומה מדומה:
- **אמיתי:** משימות, הגדרות ושיחה נשמרים ב־localStorage. הטיימר מבוסס שעון ושורד רענון. גרירה לשינוי סדר, הוספה ועריכה של משימות והפסקות, גרפים והישגים שמחושבים מהנתונים, צליל, רטט ומסך דולק (כשהדפדפן תומך).
- **מדומה ומסומן כך:** המאמן עונה מתוך תשובות מוכנות מראש, בלי AI. התראות לטלפון וחסימת אפליקציות אינן מחוברות. מצב שבת וחג פועל לפי זמנים שמוזנים ידנית.
- בהפעלה הראשונה נטענים נתוני דוגמה, והם מסומנים כך. אפשר למחוק אותם בלחיצה אחת.
