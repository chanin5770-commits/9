# אבא שלנו – קליפ יום הולדת ליוסף ❤️

עורך מקומי שבונה מהשיר המשפחתי ומהתמונות האמיתיות שלכם סרט יום הולדת קולנועי, ומייצא אותו כקובץ MP4 אמיתי.

**פרטיות:** הכול רץ על המחשב שלכם. השיר, התמונות, זיהוי הפנים, ניתוח השיר והרינדור נעשים מקומית, והשרת מאזין רק ל-`localhost`. התמונות נשמרות בתיקייה `projects/`, שלא נכנסת ל-git.

## הפעלה

צריך [Node.js](https://nodejs.org) גרסה 20 ומעלה.

```bash
cd abba-shelanu
npm install
npm start
```

אחר כך פותחים בדפדפן (Chrome מומלץ) את הכתובת **http://localhost:4321**.

בייצוא הראשון Remotion מוריד פעם אחת דפדפן רינדור (Chrome Headless Shell), ולכן צריך אינטרנט באותו רגע. מכאן והלאה הכול עובד גם בלי אינטרנט.

## איך עובדים

1. **שיר ותמונות.** מעלים את קובץ השיר (MP3, WAV או M4A) ובוחרים את תיקיית התמונות כולה (עד 150, ואפשר גם יותר). אפשר גם לגרור תיקייה לחלון. תמונות HEIC מאייפון נתמכות.
   - שמות תיקיות או קבצים כמו `משי`, `ליבי`, `הדר`, `שרי`/`שטערנא`, `יוני`/`יונתן`, `משפחה`, `טיול`, `צחוקים` מתויגים אוטומטית. גם השמות באנגלית עובדים (`meshi`, `libi`, `hadar`, `sari`, `yoni`, `family`, `trip`, `funny`).
   - השיר מנותח: אורך, קצב (BPM), כל פעמה ותיבה, עוצמה לאורך השיר, בתים ופזמונים, רגע השיא והקטעים השקטים.
   - כל תמונה עוברת זיהוי פנים, כדי שאף חיתוך או תנועת מצלמה לא יחתכו פנים.
2. **סטוריבורד אוטומטי.** המערכת מסדרת את התמונות לסיפור ומניחה אותן על השיר:
   - **פתיחה:** מסך שחור, אור רך, אבא עם אחד הילדים, הכיתובים "אבא שלנו...", "יש מתנות שאי אפשר לעטוף...", "כי הן נמצאות בלב.", ומעבר לתמונה משפחתית.
   - **אבא דרך העיניים שלנו:** אבא עם הילדים, לפי סדר כרונולוגי, כל הילדים לסירוגין, בשוטים ארוכים ושקטים.
   - **המשפחה שלנו:** תמונות משפחתיות, טיולים וצחוקים. בפזמונים יש קולאז׳ים של 2–3 תמונות ורצפים מהירים קצרים, וכל חיתוך נופל על פעמה.
   - **רגע השיא:** בפזמון החזק ביותר מופיע רצף של אבא עם כל אחד מחמשת הילדים (משי, ליבי, הדר, שרי, יוני), ואחריו, על התיבה החזקה ביותר, התמונה המשפחתית עם הכיתוב "אבא, אתה העולם שלנו."
   - **סיום:** תמונה משפחתית מלאה, הכיתוב "יוסף שלנו, תודה על כל רגע..." שורה אחרי שורה, "יום הולדת שמח, אבא!", החתימה, ודעיכה איטית לשחור שמסתיימת בדיוק עם השיר.
3. **סדר הסיפור.** גריד של כל התמונות לפי סדר הסיפור:
   - גוררים כדי לשנות סדר.
   - מתייגים ילדים ורגעים, גם להרבה תמונות בבת אחת (Ctrl/Shift).
   - מסמנים ★ על תמונות מרכזיות (הן מקבלות זמן מסך ארוך).
   - קובעים תמונת פתיחה, תמונה משפחתית, תמונת שיא ותמונת סיום.
   - מוציאים תמונות מהסרט.
   - לחיצה על תמונה מסמנת "נקודת מוקד" שלא תיחתך.
   - אחרי שינויים לוחצים "עדכון הסטוריבורד לפי הסדר שלי".
4. **עריכה.** תצוגה מקדימה חיה של הסרט, עם ציר זמן שמציג את גל הקול, החלקים, הפעמות, השוטים והכיתובים.
   - **משך שוט:** גוררים את קצה השוט או לוחצים ±פעמה. החיתוך ננעל לפעמות, והשוט הבא מתאים את עצמו, כך שהסרט תמיד מסתיים עם השיר.
   - **שוט נבחר:** אפשר להחליף בו תמונה, פריסה (בודדת או קולאז׳), תנועת מצלמה ומעבר.
   - **הגדרות כלליות:** 16:9 או 9:16, גרעין פילם, חום צבע, דליפות אור ווינייט.
   - **ביטול וחזרה:** Ctrl+Z.
5. **כיתובים ומילים.**
   - **כיתובים:** עורכים את הנוסח, הזמן, המשך והסגנון של כל כיתוב.
   - **מילות השיר:** המערכת לא ממציאה מילים. מדביקים את המילים האמיתיות ומסנכרנים אותן בהקשה על Enter בזמן שהשיר מתנגן.
   - **התאמת תמונות למילים:** שורות שמזכירות ילד ("משי") או רגע ("טיול", "חיבוק") מושכות לרגע הזה תמונה מתאימה.
   - **הצגת מילים בסרט:** אופציונלית, ורק אחרי שכל השורות מסונכרנות.
   - **תמלול אוטומטי:** אם מותקן במחשב [Whisper](https://github.com/openai/whisper) (`pip install openai-whisper`), יופיע כפתור "טיוטת תמלול מקומית". זו טיוטה בלבד, ותמלול של שירה בעברית צריך בדיקה ותיקון.
6. **בדיקה וייצוא.**
   - **בקרת איכות:** בודקת פנים שעלולות להיחתך, תמונות ברזולוציה נמוכה, מסכים שחורים לא מתוכננים, מעברים חדים או קצרים מדי, כיתובים (ריקים, חופפים, קצרים מכדי לקרוא), סנכרון החיתוכים לפעמות, שהסרט נגמר בדיוק עם השיר, ותמונות כפולות או שלא נכנסו.
   - **דוגמה מהירה:** 12 שניות סביב השיא.
   - **הסרט המלא:** 16:9 לטלוויזיה או 9:16 לטלפון, ב-Full HD או 4K.

## הקובץ שיוצא

- MP4 (H.264, yuv420p, BT.709), ‏30 פריימים לשנייה, 1920×1080, ‏1080×1920 או 4K.
- הסאונד המקורי ב-AAC ‏320kbps.
- בלי סימני מים.
- הסרטים נשמרים ב-`projects/<id>/exports/` ואפשר להוריד אותם מהממשק.

## מה המערכת לא עושה (בכוונה)

- **לא משנה אנשים:** אין שינוי פנים, גיל, בגדים או הבעות, אין אנשים חדשים ואין שחזור של רגעים שלא קרו.
- **לא מעוותת:** תמונה רק מוגדלת ומוזזת באופן אחיד, אף פעם לא מעוותת. אין תנועות שפתיים ואין חיוכים מלאכותיים.
- **עומק בלי פיקסלים מומצאים:** תחושת העומק (פרלקסה) נוצרת משתי שכבות אמיתיות, התמונה החדה מעל עותק מטושטש שלה, ולא מפיקסלים מומצאים.
- **בלי חיתוך פוגע:** כשתמונה לאורך לא נכנסת למסך לרוחב בלי לחתוך פנים, היא מוצגת בשלמותה על רקע רך.

## מבנה הקוד

| נתיב | מה יש בו |
|---|---|
| `src/shared/audioAnalysis.ts` | ניתוח השיר: FFT, זיהוי פעמות (תכנון דינמי), תיבות, עוצמה, חלקים ושיא |
| `src/shared/storyboard.ts` | סידור הסיפור החכם וחלוקת התמונות על פני השיר לפי פעמות ועוצמה |
| `src/shared/framing.ts` | מסגור ותנועות מצלמה ששומרים על הפנים |
| `src/shared/layouts.ts` | פריסות הקולאז׳ ובחירת הסידור המחמיא |
| `src/shared/qc.ts` | בקרת האיכות |
| `src/film/` | הסרט עצמו ב-Remotion (React). אותו קוד מנגן בתצוגה המקדימה ומרנדר את ה-MP4 |
| `src/ui/` | ממשק העריכה (React, עברית, RTL) |
| `server/` | שרת מקומי: קבלת קבצים, עיבוד תמונות (sharp, HEIC), שמירה ורינדור |

בדיקה עצמית של המנוע, וחומר בדיקה (שיר סינתטי ו-150 תמונות דמה):

```bash
node scripts/make-test-data.mjs test-data
npx tsx scripts/selftest.ts test-data/song.wav test-data/photos
```
