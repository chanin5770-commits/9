# המסע בדרך הארוכה־קצרה

סרט קצר (כ-9 דקות) על פרקים א׳–י״ז בתניא: מסע פנימי של יהודי אחד, ב-20 סצנות לפי הסטוריבורד.
הפרויקט בנוי ב-Remotion ו-React, עם תצוגה מקדימה בדפדפן וייצוא ל-MP4.

## מצב נוכחי: טיוטה 1, בלי קריינות

| | |
|---|---|
| **סרטון** | `out/draft-no-voice.mp4`: ‏1920×1080, ‏24fps, ‏9:22, מוזיקת רקע זמנית, בלי קריינות |
| **תזמון** | זמני (`src/data/timing.json`, ‏`status: provisional`). קצב של 24–36 שניות לתחנה, כדי שיהיה מקום להסביר כל תחנה |
| **טבלת סצנות** | [`docs/SCENES.md`](docs/SCENES.md): זמנים, שוטים, טקסט מסך ומקורות. נוצרת אוטומטית מהנתונים |

## שלבי העבודה

1. ✅ טיוטת סרטון מלאה בלי קריינות
2. ⏳ צפייה ואישור הרצף. אחרי האישור נכתוב קריינות שמתאימה לכל סצנה ולמשך שלה
3. ⏳ קריינות בשתי גרסאות: טבלה לפי סצנות עם זמנים, וטקסט רציף לכלי יצירת קול
4. ⏳ ההקלטה נעשית בכלי חיצוני. הפרויקט לא מייצר קול
5. ⏳ סנכרון: מודדים את אורך ההקלטה, מעדכנים את `timing.json` ואת הכתוביות ב-`src/data/narration.ts`, ומייצאים מחדש

## הרצה

```bash
npm install
npm run setup        # חיתוך הפריימים והקליפים, יצירת המוזיקה הזמנית וטבלת הסצנות
npm run studio       # תצוגה מקדימה בדפדפן, עם ציר זמן
npm run render       # ייצוא ל-out/draft-no-voice.mp4
```

בסביבה עם Chromium מותקן אפשר להפנות אליו, למשל:
`REMOTION_CHROME=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell npm run render`.

### החלפת תמונה בקליפ, או בתמונה איכותית

- **תמונה איכותית במקום פריים מהסטוריבורד:** שומרים אותה ב-`public/panels/NN.jpg` (אותו שם). תנועת המצלמה נשמרת, והיחס והמיקוד נשארים, כי התמונה ממלאת את הפריים ב-`cover` בלי מתיחה.
- **קליפ במקום תמונה:** מעתיקים את הקליפ ל-`source/`, מוסיפים שורה ל-`CLIP_SHOTS` ב-`tools/prepare_assets.py`, מריצים `npm run assets`, ובשוט ב-`scenes.ts` כותבים `clip('שם')` במקום `push(...)` או `wide(...)`. משך הסצנה לא משתנה, ושאר השוטים מתכווצים כדי לפנות מקום.

## החלטות עיצוב

- **מסגרת 2.39:1 עם פסים:** הפאנלים בסטוריבורד הם ביחס של כ-2.4:1 וברוחב של כ-380 פיקסלים בלבד. במסגרת קולנועית הם ממלאים את כל התמונה בלי חיתוך ובלי הגדלה מוגזמת של הפנים. סימון ההתקדמות יושב בפס העליון והכתוביות בפס התחתון, כך שאף אחד מהם לא מסתיר את הדמות. כדי לקבל 16:9 מלא: `LETTERBOX = false` ב-`src/config.ts`.
- **צבעוניות שמתחממת:** כל סצנה מקבלת `tone` (מ-1- עד 1). הפתיחה כחולה וקרירה, והסוף זהוב.
- **מבנה קבוע לכל תחנה:** שאלה, אחריה החידוש של הפרק, ואחריו המסר האישי. בתחילת כל שער מופיע כרטיס השער.
- **הבחנה בין סוגי הטקסט:** ציטוט מקור מופיע במירכאות ועם מקור. החידוש מנוסח בלשוננו ומופיע בלי מירכאות. המסר האישי מוצג כפרשנות.
- **מצב טיוטה** (`DRAFT = true`): מציג בפס התחתון את מזהה הסצנה, שמה והזמן (נוח להערות), ותגית ״דורש אימות״ ליד כל ציטוט. לכבות לפני הייצוא הסופי.

## דיוק בתוכן: דורש אימות

לא הייתה גישה למקור מקוון ולא סופק טקסט תניא בקובץ. לכן כל ציטוט מסומן ״דורש אימות מול מהדורה מודפסת״:

| ציטוט | מקור | הערה |
|---|---|---|
| ונפש השנית בישראל היא חלק אלו־ה ממעל ממש | תניא, פרק ב׳ | במקור: ״אלוה״ |
| מדת הבינוני היא מדת כל אדם | תניא, פרק י״ד | |
| בין עובד אלהים לאשר לא עבדו | מלאכי ג, יח (מבואר בתניא, פרק ט״ו) | |
| מחשבה טובה הקב״ה מצרפה למעשה | קידושין מ, א (מובא בתניא, פרק ט״ז) | |
| כי קרוב אליך הדבר מאד בפיך ובלבבך לעשותו | דברים ל, יד (תניא, פרק י״ז) | |

סיפור רבי יהושע בן חנניה (עירובין נג, ב) מובא כמשל בניסוח שלנו, בלי ציטוט ישיר. שאר הטקסטים על המסך הם ניסוחים שלנו או מסרים אישיים, ואינם מוצגים כציטוטים.

## מה עוד חסר לסרט הסופי

1. **תמונות באיכות מלאה:** כל פריים מהסטוריבורד הוא כ-380×155 פיקסלים, מוגדל פי 5 בערך, ולכן רך. צריך 20 תמונות נפרדות, לפחות 2400 פיקסלים ברוחב.
2. **קליפים נוספים:** ב-11 סצנות יש רק סטילס מונפש. רשימה ופרומפטים ל-Flow: [`docs/FLOW-CLIPS.md`](docs/FLOW-CLIPS.md).
3. **קריינות:** מגיעה בשלבים 2–5.
4. **מוזיקה מורשית:** הנוכחית היא מילוי זמני שנוצר בקוד. מחליפים ב-`<Score/>` בקובץ `src/Film.tsx`.
5. **אימות ציטוטים:** לפי הטבלה למעלה, ואחר כך `DRAFT = false`.

רישיון Remotion: חינמי ליחידים ולחברות עד 3 עובדים. ארגון גדול יותר צריך רישיון חברה.
