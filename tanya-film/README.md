# המסע בדרך הארוכה־קצרה

סרט קצר (כ-9:45) על פרקים א׳–י״ז בתניא. הוא עוקב אחר המסע הפנימי של יהודי אחד: 20 סצנות לפי הסטוריבורד, ותוכן המצגת ״הדרך הארוכה־קצרה״ בנוי בתוכן כגרפיקה.
הפרויקט בנוי ב-Remotion ו-React, עם תצוגה מקדימה בדפדפן וייצוא ל-MP4.

**עם קריינות:** הטקסט שעל הצילומים יורד, כי הקריינות מספרת את הסיפור. בתרשימים נשארים הצמתים והתוויות. בכרטיסי הטקסט הכתוביות מוצגות גדולות במרכז. בזמן הפסוק לא מוצגות כתוביות, כי הפסוק כבר על המסך. המוזיקה והאפקטים יורדים מתחת לדיבור.

### מה השתנה מטיוטה 1

- **פתיחה קרה לפני הכותרת:** לילה, אור הטלפון, רגע של התלבטות. רק אחריה באים הכותרת וצומת הדרכים.
- **שוטים של 2–6 שניות** במקום תמונה אחת מוחזקת 25 שניות. כל שוט הוא נכס אחר, ואין חיתוכים חוזרים מאותה תמונה, חוץ מחזרות מכוונות.
- **מקומות מגוונים:** בית בלילה, חדר שינה, בית כנסת, אוטובוס, משרד, מטבח עם הילד, רחוב, בית מדרש, שביל אבן, נוף ירושלים.
- **פרק י״ב כפעולה:** רטט, קריאה, היד מתחילה להקליד, עצירה בשקט מוחלט, הנחת הטלפון. המתח נשאר בפנים.
- **פרק י״ג:** חזרה מכוונת לאותם פריימים וזוויות. **פרק ט״ו:** מונטאז׳ הרגל שחוזר על עצמו, ואז שינוי מודע.
- **המצגת בתוך הסרט:** פתיחי השערים, התרשימים (המנגנון, המנסרה, ״העיר הקטנה״, טבלת צדיק־רשע־בינוני, עובד אלוקים, הגחלים) ומפת המסע, כולם בנויים מחדש ונחשפים בהדרגה.
- **טקסט גדול:** כותרות 84–120 פיקסלים, משפטים 56–72, משפט אחד בכל פעם. 16:9 מלא, בלי פסים.
- **סאונד:** רקע לכל מקום (לילה, רחוב, בית כנסת, משרד, אוטובוס, רוח), אפקטים (רטט, שעון מעורר, מים, כוס, דופק, נשימה, צעדים) ושקט מכוון לפני הבחירה.

## הרצה

```bash
npm install
npm run setup     # חיתוך פריימים וקליפים, אפקטים, טבלת סצנות ומוזיקה זמנית
npm run studio    # תצוגה מקדימה בדפדפן
npm run render    # ייצוא MP4 (עם כתוביות). בלי כתוביות: npx remotion render src/index.ts FilmClean out/film-clean.mp4
npm run table     # עדכון docs/SCENES.md ובדיקת זמני קריאה
```

בסביבה עם Chromium מותקן: `REMOTION_CHROME=/path/to/chrome npm run render`.

## דיוק בתוכן

- **ציטוט** מופיע במירכאות ועם מקור, ובטיוטה עם תגית ״דורש אימות״. לא הייתה גישה לטקסט התניא, והמצגת אינה מקור ראשוני.
- **חידוש** הוא תוכן הפרק בניסוח שלנו: בלי מירכאות, עם הפניה לפרק.
- **מסר** הוא פרשנות אישית. **משל** הוא דימוי מהמצגת, והוא מסומן ״משל״.
- **ציטוטים לאימות:** ״ונפש השנית בישראל היא חלק אלו־ה ממעל ממש״ (פרק ב׳), ״מדת הבינוני היא מדת כל אדם״ (פרק י״ד), ״בין עובד אלהים לאשר לא עבדו״ (מלאכי ג, יח; פרק ט״ו), ״מחשבה טובה הקב״ה מצרפה למעשה״ (קידושין מ, א; פרק ט״ז), ״כי קרוב אליך הדבר מאד בפיך ובלבבך לעשותו״ (דברים ל, יד; פרק י״ז).
- **תיקונים לעומת המצגת:**
  - פרק ט׳: המוח והחלל הימני לנפש האלוקית, החלל השמאלי לנפש הבהמית.
  - בטבלה: אצל הבינוני ״הרע עדיין קיים״, ולא ״לב רע״.
  - ״ניצחון תמידי״ בשקופית 20 הושמט.
- **בדיוק:**
  - מחשבה שעולה מאליה אינה מוצגת כעבירה.
  - רגע ההתגברות בפרק י״ב אינו מוצג כהוכחה למדרגת הבינוני: ״בחירה אחת. ועוד אחת.״, ולמחרת המאבק חוזר.
  - בסיום הדמות עדיין מתמודדת.

## מה עוד חסר לסרט הסופי

1. **קליפים:** 53 שוטים הם סטילס זמניים. הרשימה, לפי סדר עדיפות, ב-[`docs/FLOW-CLIPS.md`](docs/FLOW-CLIPS.md).
2. **עקביות הפנים:** בסטוריבורדים ובקליפים הדמות דומה לתמונות הרפרנס, אבל לא זהה להן. בשוט האוטובוס ההבדל בולט.
3. **קריינות:** כתיבתה מחכה לאישור הרצף. ההקלטה תיעשה בכלי חיצוני.
4. **מוזיקה ואפקטים:** אלה הנוכחיים הם מילוי זמני שנוצר בקוד. לסרט הסופי כדאי להחליף אותם במוזיקה ובאפקטים מורשים.
5. **אימות ציטוטים**, ואחר כך `DRAFT = false` ב-`src/config.ts`.
