## במה השתמשתי

כל החומרים קיימים בפרויקט. לא נוצרו דמויות חדשות.

- **מלך האותיות:** קטעי הדמות מהקליפ שלו, `desk-aleph` ו-`hall-pointing`.
- **מלכת האותיות:** קטעי הדמות מהקליפ שלה, `first-letter` ו-`letter-hall`. קטע הריקוד לא נכלל, כי השמלה מתרוממת בו.
- **הערכה:** הכריכה, כרטיסיות הענק של א׳ וב׳, וכריכות משחקי הלוטו והזיכרון ושל משחקי מלך ומלכת האותיות. כולם נחתכו מהתמונות שצירפת ב-`assets/kit/`, בלי שום שינוי בתוכן.
- **עיצוב:** אותיות תלת־ממד, ניצוצות, חלון בצורת קשת, כתר וקשת 22 האותיות, כולם מהמנוע של הקליפ (`src/engine.js` ו-`src/scenes.js`). כל אות וכל מילה נכתבות בגופן אמיתי: Frank Ruhl Libre, ‏Secular One ו-Rubik.
- **מוזיקה:** הקטע האינסטרומנטלי מהשיר ״מלכת האותיות״ (0:36.1–0:47.5, בלי שירה), בקצב 147 BPM. כל חיתוך נופל על תחילת תיבה.

## רינדור מחדש

```bash
sh tools/extract-frames.sh                       # פעם אחת: פריימים ל-build/frames
python3 tools/make_music.py <malchat-haotiyot.mp3> assets/launch-music.wav
node tools/render.cjs --page launch-teaser.html --audio assets/launch-music.wav --out build/master.mp4
ffmpeg -i build/master.mp4 -c:v libx264 -profile:v high -crf 20 -maxrate 6M -bufsize 12M -pix_fmt yuv420p \
  -c:a aac -b:a 192k -movflags +faststart dist/melech-umalka-launch-teaser-9x16.mp4
```

השוטים והתזמונים נמצאים ב-`src/launch.js`.
